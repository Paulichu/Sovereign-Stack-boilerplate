How to publish the asset
------------------------
Maintainers can create the release locally by running the script `scripts/create_bundle_zip.sh` (it zips the `bundle/` directory to `releases/bundle-v1.0.zip`) and then uploading the produced ZIP as a Release asset on GitHub (Releases → Draft a new release → upload asset).
