This folder contains a small placeholder and instructions for the release asset.

What to do to publish the asset:
1. Run: chmod +x scripts/create_bundle_zip.sh
2. Run: ./scripts/create_bundle_zip.sh
   -> produces releases/bundle-v1.0.zip
3. On GitHub: Go to Releases → Draft a new release → Tag: bundle-v1.0 → Upload the ZIP as asset

If you want, I can prepare a draft release body (title/description) to paste when creating the GitHub Release.
